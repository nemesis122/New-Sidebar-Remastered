# Sidebar Remastered by NemeSIS v1.01.0.0

Portable Windows x64, .NET included. **EXE and matching source ZIP are both attached.** Four new glass designs, each with its own form, and a clearer Smoke Glass.

## New designs

| Design | Form |
| --- | --- |
| **Glass Tiles** | Readings as two-column glass tiles that fill from the bottom; label and value in the upper corner. |
| **Glass Columns** | An equalizer of vertical glass tubes, value and label centred beneath each tube. Cards with fewer than three bars use slim tubes. |
| **Glass Ring** | The main reading inside a 270-degree glass ring that fills to its level; all other readings as slim tubes. |
| **Glass Inline** | The densest design: one line per reading with label, short glass bar and value on shared column edges. |

All four follow every setting: line/bar thickness, graphic size, colors, text sizes and visibility, warning colors, light themes and the shared HW Sensors frame. Throughput keeps its live 60-second trace in every design.

## Changed

- **Smoke Glass:** the fill is now translucent smoke with a glowing top edge instead of a bright opaque liquid, so labels stay readable.

## Download and update

Download **Sidebar-Remastered-v1.01.0.0.exe** and replace the previous EXE; keep `remastered-settings.json` beside it so your settings carry over. **Sidebar-v1.01.0.0-Source.zip** is the matching source. The EXE is unsigned. See **VALIDATION.txt** and **SHA256SUMS.txt** for test scope and integrity.
