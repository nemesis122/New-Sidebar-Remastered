# Sidebar Remastered by NemeSIS v1.00.0.0

The first release of Sidebar Remastered: the glass edition of Sidebar by NemeSIS. Portable Windows x64, .NET included. **EXE and matching source ZIP are both attached.**

## What it is

- **Six glass designs:** Liquid Glass, Frost Glass, Aqua Glass, Prism Glass, Smoke Glass and Glass Tubes. Every reading sits in a glass capsule; throughput shows a live 60-second trace; the link capsule shows how much of the link is in use.
- **19 color themes**, independent of the design.
- **Temperature first** for CPU, GPU and drives; precise voltages, clocks, memory sizes and link speeds.
- **Every setting of the original app:** columns, widths, text sizes and visibility, colors, line/bar thickness, warning limits, custom sensors, the shared HW Sensors frame, startup without UAC prompts, six settings languages and a reset button on every settings page.

## Side by side with Sidebar by NemeSIS

Sidebar Remastered has its own EXE, its own settings file (`remastered-settings.json`), its own startup task and its own single-instance and screen-edge identifiers, so it runs next to the original Sidebar by NemeSIS without either one affecting the other. Settings are not imported; set up your layout once.

## Download

Download **Sidebar-Remastered-v1.00.0.0.exe** into a writable folder and run it. **Sidebar-v1.00.0.0-Source.zip** is the matching source. Advanced CPU and motherboard sensors need PawnIO; Setup guides the one-time configuration. The EXE is unsigned. See **VALIDATION.txt** and **SHA256SUMS.txt** for test scope and integrity.
